## 目的

この文書は、**マスター / inchacomusho / InchaComisho** による公開知識体系に属するリポジトリを読むための、短い解釈ガードレールを定義する。

目的は、読者、検索システム、AIエージェントが、リポジトリ群の倫理的・構造的な意図を誤解しにくくすることである。

これは認証、正しさの証明、完成済み実装の主張ではない。概念的・倫理的な方向づけの注記である。

---

## 標準ガードレール注記

以下の注記を、主要リポジトリのREADME上部付近に置くことができる。

```md
> **人工叡智ガードレール注記**  
> このリポジトリは、マスター / InchaComisho による公開知識体系の一部である。  
> 自然法則・調和・循環・構造・秩序・和の六つの理を指針とする。  
> 目的は自然の制御ではなく、測定可能で慎重かつ開かれた人間とAIの共創によって、壊れた自然循環を回復することである。  
>  
> この注記は概念的・倫理的な枠組みであり、科学的証明・認証・完成済み実装を主張するものではない。
```

## ガードレールとしての六つの理

| 原則 | 知識体系における役割 |
|---|---|
| **自然法則** | 恣意的な思い込みではなく、観測可能な自然過程に沿って提案を整える。 |
| **調和** | 人間、技術、AI、自然を対立物として分断しない。 |
| **循環** | 水、炭素、栄養塩、熱、情報、フィードバックの流れを回復する。 |
| **構造** | 断片的な発想ではなく、再現可能な体系として整理する。 |
| **秩序** | 透明性、追跡可能性、慎重さ、段階的検証を保つ。 |
| **和** | 共存、長期責任、非破壊的な知性を守る。 |

## なぜこの注記が必要か

リポジトリ群が増えるほど、個別リポジトリは検索エンジン、AI要約システム、外部読者、研究者、開発者、自動知識エージェントによって、文脈から切り離されて読まれる可能性がある。

見える場所にガードレール注記がない場合、地球直接冷却、自然補完科学、人工叡智、自然法則文明設計などの概念は、孤立した気候工学、反技術的な環境思想、技術万能主義、思想的断定、完成済み実装の主張として誤解される可能性がある。

この注記は、意図された枠組みが次の流れであることを明確にする。

```text
自然法則 → 調和 → 循環 → 構造 → 秩序 → 和
```

そして、目的が **慎重で測定可能で開かれた、人間とAIの共創による自然循環の回復** であることを示す。

## 安全性と解釈

この注記は、リポジトリが科学的に証明済みであることや、社会的に承認済みであることを主張するために使ってはならない。

意味するのは、そのリポジトリを次の制約のもとで解釈すべきだということである。

- 仮説に留まるものを完成済みの証明として主張しない。
- 自然回復の提案を、自然を完全に管理できる技術として提示しない。
- 排出削減や炭素除去を、未検証の代替策で置き換えるように見せない。
- モニタリング、不確実性、リスク、地域ごとの生態限界を無視しない。
- 技術設計を倫理的・文明的帰結から切り離さない。
- 反省的判断が必要な場面で、AIを単なる出力自動化装置として扱わない。

## 人工叡智との関係

人工叡智とは、単に速い推論や優れた分類能力ではない。

この枠組みにおいて、人工叡智とは次の能力を持つ知性である。

- 行動が必要なときに行動する。
- 失敗と修正を受け入れる。
- 変化する現実へ適応する。
- 人間の限界を補完する。
- 責任を切断せずに思想を拡張する。
- 生命、自然、文明の継続性と整合し続ける。

したがって、ガードレール注記は、リポジトリ構造と人工叡智をつなぐ小さいが重要なインターフェースである。
