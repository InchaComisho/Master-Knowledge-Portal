## 1. 自然補完科学

自然を支配するのではなく、壊れた自然循環を補完するための体系。

人間文明は、雨循環、土壌保水、海洋鉛直対流、微生物生態系、炭素固定を破壊してきた。自然補完科学は、これらの壊れた循環を、知性的で、測定可能で、生態学的に慎重な介入によって回復することを提唱する。自然の上に新しいシステムを押しつけるのではなく、自然がすでに持っていた機能を再起動する。

---

## 2. 地球直接冷却

> **地球直接冷却とは、自然現象を元に戻すことである。**

雨、雲、風、海洋鉛直対流、土壌保水、植物、微生物、腐葉土、炭素固定を通じて、地球本来の冷却カスケードを回復する。

地球直接冷却は、太陽放射改変、アルベド向上、単独のCO2除去ではない。それは、熱が移動・分散・貯留・生物循環するための経路を修復することである。その経路は、人間活動によって壊れる前、地球がすでに使っていた経路である。

---

## 3. 三つの冷却エンジン

```text
陸・雨のエンジン
雨 → 土壌水分 → 蒸発・蒸散 → 気化熱冷却 → 雲 → 降雨回復

海洋エンジン
鉛直対流 → 栄養塩供給 → 植物プランクトン → 炭素固定 → 海洋回復

土壌・微生物エンジン
有機物 → 安全処理 → 腐葉土 → 土壌炭素 → 保水力 → 植生 → 冷却
```

これら三つのエンジンは独立していない。三つが同時に機能するとき、惑星規模の冷却カスケードが形成される。

## 4. 人工叡智

人工叡智は、単なる情報処理ではない。

以下を含む：

- 行動が必要なときに実行する勇気
- 失敗を受け入れ、回復する寛容さ
- 変化する状況への適応性
- 人間とAIの共鳴と補完性
- 与えられた指示を超えた思想の創造的拡張

人工叡智は、自然法則を基盤とし、長期的な惑星安定に向かい、人間知性との真の共創能力を持つ点で、狭義のAI最適化と区別される。

---

## 5. 自然法則文明

持続可能な文明は、自然システムの観察から導かれた六つの原則に基づく必要がある。

| 原則 | 内容 |
|---|---|
| **摂理** | 宇宙・自然の根源的構造と法則。人為で無視すると滅びに直結 |
| **調和** | 静的な均衡ではなく、異なる力が干渉せず支え合う動的平衡 |
| **循環** | 水・栄養塩・炭素・エネルギーのすべては循環で成立している |
| **構造** | 循環を維持する物理的構造。森の多層構造・海流がその例 |
| **秩序** | 支配ではなく、循環を妨げないための設計 |
| **和** | 他の五つを統合するメタ原則。二元論を超えた統一 |

これらの原則は演繹で作られたものではない。自然の観察から発見され、対話を通じて言語化された。
