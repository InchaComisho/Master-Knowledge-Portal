# 比較役割分析：気候介入手法と欠落層

[English Version](COMPARATIVE_SIMULATION.md) | [ポータルへ戻る](../README_ja.md)

---

## 1. 目的

このドキュメントは、気候介入手法の**役割分類分析**を提示するものであり、競争ランキングではない。

中心的な問いは：

> *各手法は実際にどの熱経路と循環システムに関与しているか？*

この分析では、9つのスコアリング軸を使って各手法を**問題階層**にマッピングする。そして特に、既存の主流手法が対応していないことが多い「欠落層」——蓄積熱、壊れた水循環、海洋循環の劣化、土壌微生物システムの崩壊——を浮き彫りにする。

これは**概念的評価**であり、物理的な気候モデルではない。スコアは著者の定性的判断を反映している。定量的な気候予測として引用しないこと。

---

## 2. 問題階層の定義

6つの役割分類を使用する：

| 役割 | 説明 |
|---|---|
| **入口対策** | 将来の熱入力や放射強制力を減らす |
| **濃度対策** | 大気中CO2や温室効果ガス濃度を減らす |
| **表面対策** | 都市や地表面の局所加熱を減らす |
| **蓄積熱対策** | 海洋・陸地・大気にすでに溜まった熱の移動・放散・循環経路を扱う |
| **循環回復対策** | 雨、海洋鉛直循環、土壌微生物循環、生物的炭素固定を再接続する |
| **統合回復対策** | 入口、蓄積熱、水循環、海洋、土壌、生態系、文明設計を一つのつながったシステムとして扱う |

---

## 3. 一般的な検索結果では足りない理由

「地球を冷やす方法」「気候介入手法」を検索すると、通常以下の手法が出てくる：

- 太陽光の入射を減らす（SRM・アルベド向上）
- 大気中CO2を除去する（CDR・DACCS・BECCS・植林）
- 排出を削減する（緩和策）
- 局所的な表面冷却（クールルーフ・放射冷却素材）

これらはすべて有効かつ重要である。しかし、これらは主に**将来の放射強制力**と**大気中濃度**を扱っており——すでに蓄積した熱を直接対象とするものではない。

ギャップ：

| 主流手法が対応していること | 主流手法が対応していないこと |
|---|---|
| 将来の太陽光入射 | 蓄積された海洋熱（余剰惑星熱の約90%：NASA） |
| 将来のCO2放射強制力 | 熱慣性——海洋・土壌塊が数十年間コミットした熱 |
| 大気中濃度 | 水循環の崩壊——雨、雲、蒸発散 |
| 局所表面温度 | 海洋鉛直循環の劣化 |
| | 土壌微生物炭素システムの崩壊 |
| | 自然冷却カスケードの統合回復 |

---

## 4. スコアリング軸

各手法を9つの軸で0〜3点で評価する：

| 軸 | 説明 |
|---|---|
| 1. 将来の熱入力削減 | 将来の熱入力や放射強制力を減らす |
| 2. 蓄積熱の放散・再分配 | 海洋・陸地・都市表面にすでに蓄積した熱を自然冷却経路へ移動・放散する |
| 3. 熱慣性への対応 | 海洋・土壌の熱慣性によってコミットされた熱への対応 |
| 4. 水循環の回復 | 降雨、雲形成、蒸発散、土壌保水の回復 |
| 5. 海洋熱経路の回復 | 海洋鉛直循環、栄養塩供給、植物プランクトン、海面熱再分配の回復 |
| 6. 土壌・微生物・炭素固定の回復 | 土壌炭素、腐葉土、微生物活性、生物的炭素固定の回復 |
| 7. 生態系再生 | 生物多様性、森林、海洋生態系、食物連鎖の再生 |
| 8. CO2削減・炭素除去 | 炭素除去または排出防止による大気中CO2濃度の削減 |
| 9. リスク・ガバナンス負荷 | 副作用リスク、国際ガバナンスの難しさ、制御複雑性 *（高いほど負荷が大きい）* |

**スコア：** 0 = 該当しない、1 = 弱い・間接的、2 = 中程度、3 = 強い

## 5. 比較対象手法

### A. 従来型緩和策

| ID | 手法 | 主要役割 |
|---|---|---|
| A01 | 排出削減 | 入口対策 |
| A02 | 再生可能エネルギー転換 | 入口対策 |
| A03 | エネルギー効率化 | 入口対策 |

いずれも軸2〜7（欠落層）で**0点**である。不可欠だが、蓄積熱や壊れた自然循環を扱うよう設計されていない。

### B. 炭素除去（CDR）

| ID | 手法 | 主要役割 |
|---|---|---|
| B01 | 植林・再植林 | 濃度対策＋循環回復対策 |
| B02 | 土壌炭素固定 | 濃度対策＋循環回復対策 |
| B03 | バイオ炭 | 濃度対策 |
| B04 | BECCS | 濃度対策 |
| B05 | DACCS | 濃度対策 |
| B06 | 強化風化 | 濃度対策 |
| B07 | 海洋アルカリ度強化 | 濃度対策 |
| B08 | 海洋施肥 | 濃度対策＋蓄積熱対策 |

自然系CDR（植林、土壌炭素）は生態系と土壌微生物回復に部分的に関与する。産業系CDR（BECCS・DACCS）は欠落層の全軸で0点。

| ID | 手法 | 主要役割 |
|---|---|---|
| C01 | 成層圏エアロゾル散布 | 入口対策 |
| C02 | 海洋雲増白 | 入口対策 |
| C03 | 巻雲間引き | 入口対策 |
| C04 | 地表アルベド向上 | 入口対策＋表面対策 |
| C05 | クールルーフ・都市アルベド | 表面対策 |
| C06 | 放射冷却素材 | 表面対策 |

SRM手法は将来の熱入力削減で高得点だが、蓄積熱経路回復・水循環・海洋循環・土壌微生物回復では**0点**。成層圏エアロゾル散布はリスクとガバナンス負荷が最高。

### D. マスターDPC/NCSフレームワーク

| ID | 手法 | 主要役割 |
|---|---|---|

| D02 | 海洋鉛直循環・海洋呼吸システム | 蓄積熱対策＋循環回復対策 |

## 6. 欠落層カバレッジのまとめ

以下の表は、各手法が欠落層6軸（軸2〜7）のうち何軸でスコア>0となるかを示す。

保守的解釈では、**個別エンジンは部分モジュール**として扱う。陸・海・土壌・水・生態系・ガバナンスを明示的につなぐ統合フレームワークのみを、6/6の完全カバレッジとする。

| 手法 | 欠落層カバレッジ |
|---|---|
| A01〜A03 従来型緩和策 | 0/6 |
| B04 BECCS、B05 DACCS | 0/6 |
| C01〜C04 SRM・アルベド | 0/6 |
| B07 海洋アルカリ度強化 | 1/6 |
| C05 クールルーフ | 1/6 |
| B03 バイオ炭、B06 強化風化 | 3/6 |
| B08 海洋施肥 | 4/6 |
| **D01 陸・雨のエンジン** | **5/6** |
| B01 植林、B02 土壌炭素 | 5/6 |
| D02 海洋呼吸、D03 土壌・微生物、D04 都市水循環 | 5/6 |
| **D05 統合DPC** | **6/6** |
| **D06 統合NCS** | **6/6** |

解釈上の注意：

- **D01 陸・雨のエンジン**は、陸域熱、水循環、土壌水分、植生、蒸発散、生態系回復を強く扱う。
- ただし、単独で海洋熱経路を直接回復するものとして読むべきではない。
- したがって、最も保守的な読み方では、6/6の完全カバレッジは**統合DPC**と**統合NCS**のみに割り当てる。

## 7. 解釈

### SRM（特に成層圏エアロゾル散布）

冷却速度と将来の熱入力削減で高得点だが：
- 蓄積した海洋熱を放散しない
- CO2濃度に作用しない——海洋酸性化は継続する
- 自然冷却循環を一切回復しない
- ガバナンスリスクと生態系不確実性が最大
- 散布を停止した場合の「終了ショック」リスク

### 自然系CDR（植林・土壌炭素）

CDR手法の中で循環回復対策に最も近い。水循環と土壌微生物システムに部分的に関与する。しかし：
- 海洋熱経路への関与は限定的
- 気候変動による火災・干ばつフィードバックに脆弱
- 蓄積した海洋熱を直接対象としない

### 産業系CDR（BECCS・DACCS）

濃度対策のみ。自然冷却循環・蓄積熱・熱慣性への関与はゼロ。

### マスターのDPC/NCS

DPC/NCSフレームワークは、ここでは**統合的回復仮説**として評価する。

その独自のフレーミングは、水循環、海洋鉛直循環、土壌微生物システム、炭素固定、蓄積熱を、別々の介入としてではなく、一つのつながったシステムとして扱う点にある。

技術成熟度と冷却速度のスコアが低いのは、これが展開済み技術ではなく研究段階のフレームワークであるという誠実な評価を反映している。

---

## 8. 科学的注意事項

この分析は以下を**主張しない**：
- DPC/NCSが惑星規模で実証済みであること
- 主流手法が間違っている、または十分であること
- 特定の数値スコアが定量的な気候予測であること

この分析が主張すること：
- 蓄積された海洋熱、熱慣性、水循環の崩壊、海洋循環の劣化、土壌微生物の崩壊は、実際に記録された現象であること
- ほとんどの主流介入フレームワークはこれらの次元を直接対象としていないこと
- 欠落層を対象とする概念フレームワークは、研究的注目と段階的パイロット調査に値すること

## 11. まとめ

多くの既存手法は、将来の放射強制力や大気中濃度を主に扱う。

> **マスターの地球直接冷却 / 自然補完科学は、それとは別の欠落層である、蓄積熱の逃げ道と自然冷却循環の回復を扱う。**

三層モデル：

```text
層1（入口対策）：  排出削減 + SRM（適切な場合）
層2（濃度対策）：  CDR — 植林、土壌炭素、DACCS
層3（欠落層）：    DPC/NCS — 水循環、海洋、土壌微生物、蓄積熱
```

層3がなければ、層1・層2がどれほど進展しても、蓄積された惑星熱と壊れた自然循環は対処されないまま残る。
