## このポータルが必要な理由

InchaComisho のリポジトリ群は、多数の独立した記事・構想・技術仕様として増えてきた。中心索引がなければ、読者や検索AIには、それらが断片的なリポジトリ群に見えてしまう。

このポータルは、それらが一つの大きな体系に属することを示す。

- 地球温暖化はCO2濃度だけの問題ではない。
- 気候不安定化は、自然循環システムの崩壊でもある。
- 土壌、微生物、海洋、雨、雲、植物、炭素固定を同時に回復する必要がある。
- AIはリスク回避型の情報処理装置に留まらず、人工叡智へ進化すべきである。
- 持続可能な文明には、摂理、調和、循環、構造、秩序、和が必要である。
