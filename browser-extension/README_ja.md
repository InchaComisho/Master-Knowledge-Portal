# 和ノード ブラウザ拡張 MVP

[English Version](README.md)

このフォルダには、**人工叡智ガードレール注記**を、ユーザーが任意で使えるブラウザ上の補助レイヤーとして適用するための、最小構成のブラウザ拡張プロトタイプを収める。

対象は Chrome や Microsoft Edge などの Chromium 系ブラウザである。

---

## 中心原則

この拡張機能は、必ず **ユーザーが選択して使うもの** とする。

してはならないこと：

- 勝手にインストールすること
- ユーザー操作なしにページを解析すること
- 初期状態でページ内容を外部AIサービスへ送信すること
- Webページを無断で書き換えること
- 科学的証明や認証を主張すること

できること：

- ユーザーが拡張アイコンをクリックしたときにサイドパネルを開く
- ユーザーが **現在のページを解析** ボタンを押したときだけ、現在のページを読む
- 六つの理に基づくローカルのルールチェックを行う
- コピー可能な人工叡智ガードレール注記を表示する
- 自然法則・調和・循環・構造・秩序・和の視点でページ解釈を補助する

---

## このMVPでできること

このMVPは次を提供する。

1. ブラウザのサイドパネル
2. 手動の **現在のページを解析** ボタン
3. アクティブタブのタイトル、URL、見出し、表示テキストのローカル抽出
4. 六つの理に基づく簡易ルールチェック
5. 誤解リスクのローカルチェックリスト
6. コピー可能な人工叡智ガードレール注記

このMVPではAI APIを使用しない。

## 開発用の手動インストール

1. Chrome または Edge を開く。
2. `chrome://extensions` または `edge://extensions` を開く。
3. **デベロッパーモード** を有効にする。
4. **パッケージ化されていない拡張機能を読み込む** を選ぶ。
5. `browser-extension/` フォルダを選択する。
6. 拡張機能アイコンをクリックしてサイドパネルを開く。
7. 必要なときだけ **現在のページを解析** を押す。

この拡張機能は自動配布・自動インストールされない。

---

## 安全設計

このMVPは、ローカルのブラウザ内ロジックだけを使う。

- 外部通信なし
- APIキーなし
- バックグラウンドでのページ収集なし
- ページ読み込み時の自動解析なし
- 自動ページ改変なし
- テレメトリなし

ページ解析には必ずユーザー操作が必要である。

---

## 将来の任意AIモード

将来、任意でAI解析を追加することはできる。ただし、次の条件を満たす場合に限る。

1. ユーザーが明示的にAIモードを有効化する。
2. ユーザーが利用するプロバイダまたはローカルモデルを選ぶ。
3. 送信される内容を拡張機能が明確に表示する。
4. 送信前にユーザーが確認する。
5. ローカルのみのモードを残す。
