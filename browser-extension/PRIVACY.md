# Privacy Policy for Wa Node Browser Extension MVP

This MVP is designed as a local, user-controlled browser extension.

## Data Collection

This extension does not collect, store, sell, transmit, or share personal data.

## Network Requests

This MVP does not make external network requests.

## Page Analysis

The extension reads the current tab only when the user clicks **Analyze current page**.

The extracted text is processed locally in the browser and is not sent to any external service.

## AI Services

No AI API is used in this MVP.

If an optional AI mode is added in the future, it must be disabled by default and require explicit user confirmation before any page content is sent.

## Permissions

The extension uses minimal permissions for active-tab analysis and side-panel display.

## Telemetry

This MVP has no analytics, telemetry, tracking, or remote logging.

## User Control

The extension is not installed automatically. Users must manually load or install it.

Users choose when to open the side panel and when to analyze a page.
